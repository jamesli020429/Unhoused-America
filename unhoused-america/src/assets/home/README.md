# Homepage image assets

Place homepage images in this folder using these filenames:

- `about-feature.jpg` — large image in the About the Project section
- `about-detail-01.jpg` — first small About image
- `about-detail-02.jpg` — second small About image
- `components-embodicons.jpg` — Embodicons card image
- `components-map.jpg` — Map card image
- `components-timeline.jpg` — Timeline card image
- `submissions-feature.jpg` — large Call for Submissions image

Use JPG for photographs when possible. PNG is also fine when transparency is needed.
